\begin{abstract}
With the rapid scaling of large language models (LLMs), their emergent abilities have exhibited an impressive spectrum of capabilities. Among these, in-context few-shot learning—where models effectively generalize from only a handful of examples—has elicited notable interest, inspiring a surge of research into it. However, these efforts have primarily focused on textual and visual modalities, with limited exploration of complex numerical data such as Electroencephalography (EEG) signal.
While a few recent works have explored fine-tuning LLMs for brain-computer interface (BCI) tasks, to the best of our knowledge, none have directly leveraged prompt engineering—a simple yet powerful approach—to unlock LLMs’ in-context learning ability for EEG-based classification. Notably, as many large-scale models are only available through Model-as-a-Service (MaaS) APIs, which prohibit user-side fine-tuning, prompt engineering becomes the only viable means to exploit the capabilities of these powerful but closed-source models.
In this paper, we propose a novel method that integrates domain-specific feature extraction with a purity-guided active selection strategy to identify a small set of informative exemplars from a large sample pool. For example, in Motor Imagery (MI) tasks, we apply common spatial pattern (CSP) filtering to extract discriminative EEG features. We then compute the proportion of each sample’s $k$-nearest neighbors that share the same label, rank all samples by this ratio in descending order, and select the top-ranked ones with the highest local same-label purity.
These high-purity exemplars are then embedded in prompts as demonstrations, enabling LLMs to perform EEG classification in a few-shot setting—without any gradient-based parameter updates. Notably, our exemplar selection is performed only once, unlike conventional Natural Language Processing (NLP) tasks where exemplars must be re-selected for each test instance. This significantly reduces computational cost and inference latency.
Extensive experiments across multiple EEG datasets, BCI paradigms, and LLM models demonstrate that our method consistently outperforms random selection baselines, delivering superior accuracy and stability. Furthermore, performance improves with more powerful LLM (e.g., DeepSeek-V3), and in some cases, our approach even surpasses state-of-the-art supervised models.
\end{abstract}

\section{Introduction}

Transformer-based pre-trained large language models (LLMs) have achieved remarkable progress across a wide range of natural language processing (NLP) tasks \cite{}. As their size increases, these models gain the ability to perform in-context learning (ICL), where a small number of demonstration examples provided at inference time enable the model to achieve state-of-the-art (SOTA) or near-SOTA performance—without any parameter updates \cite{}.
However, in many real-world applications, language alone is insufficient. Different tasks often rely on non-linguistic modalities to convey information, and textual inputs may not fully capture the necessary signals. To bridge this gap, various efforts have been made to integrate LLMs with other modalities such as images \cite{}, audio \cite{}, video \cite{}, and physical actions \cite{}. Nevertheless, applying LLMs to EEG signals presents a distinct set of challenges. EEG data suffers from limited high-quality annotations, especially aligned EEG-text pairs. Furthermore, EEG signals are inherently non-stationary, exhibit high inter-subject variability, and possess a low signal-to-noise ratio—making few-shot learning with raw EEG data particularly difficult.

An alternative strategy is to embed numerical signals into textual templates, allowing LLMs to process them as prompts. Prior studies have explored such methods for structured data like tables or medical records \cite{}, where values typically carry semantic meaning and can be easily verbalized. In contrast, EEG signals lack inherent semantic interpretability. For instance, the number “16” in a clinical record may indicate a meaningful age, whereas the same value in EEG data might simply represent an arbitrary signal amplitude at a specific time point, devoid of symbolic meaning.
In addition, EEG data is high-dimensional and temporally dense. A 2-second EEG trial sampled at 256 Hz across 8 channels yields 4,096 numerical values. Directly inputting such dense, unstructured data into an LLM consumes excessive tokens and hinders the model’s ability to learn meaningful patterns. As a result, grounding LLMs in low-semantic, large-scale numerical domains like EEG remains underexplored.

To address these challenges, incorporating domain knowledge to extract discriminative and compact features from raw EEG signals is both essential and effective. In our experiments on MI tasks—which primarily elicit event-related desynchronization (ERD) and synchronization (ERS) patterns in the $\mu$ (8–13 Hz) and $\beta$ (13–30 Hz) frequency bands over the sensorimotor cortex, particularly around electrodes C3 and C4—we drew inspiration from the Filter Bank Common Spatial Pattern (FBCSP) framework \cite{}. Specifically, we found that applying bandpass filtering in the 8–24 Hz range, dividing the spectrum into four 4-Hz sub-bands, and extracting two CSP features from each sub-band significantly enhanced classification performance.

Just as in NLP tasks, selecting appropriate in-context examples is crucial for model performance \cite{}. Prior work has proposed selecting examples based on semantic similarity \cite{} or using clustering to balance similarity and diversity \cite{}. These methods aim to identify examples that are both informative and representative, maximizing the full potential of large language models.
However, we find that such strategies are not directly effective for EEG signal classification. Based on extensive experimentation and analysis, we propose a new example selection method tailored for EEG features and other types of complex numerical data. Our method differs from standard NLP in-context selection approaches in two key ways.

First, instead of selecting exemplars for each test instance individually as commonly done in NLP, we select a fixed set of examples from the training pool once at first, and reuse them for all test samples. This significantly reduces computational overhead.
Second, in the context of EEG signal classification, we find that prompting the LLM with class-consistent, low-entropy exemplars from each category consistently improves accuracy. In contrast, using high-entropy, hard-to-predict samples results in poor performance, while mid-level examples—such as those near the cluster center—fall somewhere in between.

Based on these observations, we propose a simple yet effective algorithm that selects high-confidence exemplars by estimating local same-label purity—defined as the proportion of same-label neighbors within a $k$-nearest neighborhood. This selection strategy identifies exemplars with the highest intra-class consistency for prompting, and achieves significantly better and more stable performance than random selection across multiple BCI paradigms and EEG datasets.

In summary, our contributions in this paper are:
\begin{enumerate}
\item To the best of our knowledge, this work is the first to directly explore the feasibility of using LLMs for classifying EEG signals via in-context few-shot prompting, thereby extending the application of LLMs to complex, low-semantic numerical domains beyond natural language.
\item We incorporate domain knowledge to extract compact and task-relevant features from raw EEG signals. This not only reduces the number of input tokens substantially but also improves classification performance, making the LLM-based prompting pipeline more effective and computationally feasible.
\item Unlike prior work in NLP that performs example selection per test instance, we introduce a fixed exemplar set that is selected once from the training pool and reused across all test samples. This strategy significantly reduces computational cost and inference latency.
\item We propose a novel exemplar selection strategy based on local same-label purity, which identifies low-entropy, class-consistent samples as prompts. Our findings challenge common assumptions in prompt construction and demonstrate that such exemplars consistently lead to superior and more stable performance across multiple BCI paradigms and EEG datasets.
\end{enumerate}

\section{Related Works}

\subsection{Few-shot Prompting}
With the rapid advancement of LLMs, ICL has emerged as a powerful paradigm that enables models to perform downstream tasks by conditioning on a small set of input–output examples without updating model parameters. A particularly effective and widely adopted form of ICL is few-shot prompting, wherein a handful of labeled demonstrations are provided in the prompt during inference. This approach has achieved competitive, and sometimes even state-of-the-art results across diverse tasks.

\subsection{Demonstration Selection for Few-shot Prompting}
Despite its simplicity, the success of few-shot prompting depends heavily on the selection and arrangement of demonstration examples. Poor example quality or ordering can lead to degraded performance or unintended biases.

In existing studies on demonstration selection for ICL, several strategies have been proposed. \cite{liu-etal-2022-makes} proposed to select demonstrations based on similarity, retrieving the k nearest neighbors of a test instance using sentence encoders to compute distances in the embedding space. \cite{li-etal-2024-self-prompting} incorporate diversity by clustering the sample pool and then selecting the nearest sample to the test instance from each cluster. In the field of computer vision, recent work has extended this idea by assigning a similarity-based score (e.g., cosine distance) to each candidate, reflecting its suitability for inclusion in the prompt \cite{zhang2023makes}.

Overall, current research on ICL demonstration selection is primarily focused on NLP and CV tasks, with selection criteria centered around similarity to the query, representativeness, diversity, and uncertainty.

\subsection{EEG-based Classification}
EEG-based classification tasks cover a wide range of scenarios, such as motor imagery, sleep stage classification, and epilepsy detection. Traditional approaches typically rely on feature extraction methods like CSP, followed by classifiers such as logistic regression (LR) or support vector machines (SVM). In recent years, deep learning models—particularly those based on convolutional neural networks (CNNs)—have been proposed and have achieved state-of-the-art performance across various tasks. However, due to the limited size of available EEG datasets, the scale of these models remains constrained, making it infeasible to train models comparable in size to LLMs or large vision models (LVMs).

\cite{jiang2024large} introduced a 0.369B-parameter model trained on a large collection of EEG data spanning multiple paradigms and tasks, which represents one of the largest models in the EEG domain to date. Nonetheless, its performance and ease of use in downstream tasks still lag far behind that of LLMs. Due to the modality gap, LLMs cannot be directly applied to EEG-based tasks. To the best of our knowledge, no prior work has directly applied prompt engineering to EEG classification tasks.



\section{Method}
In our setting, we start with a large pool of labeled training samples. Our objective is to select a small subset of these samples to serve as in-context examples within the prompt, aiming to best activates the few-shot capabilities of a LLM and maximizes its performance on the test set. Throughout the entire prediction process, we do not update the model’s parameters, ensuring the simplicity of the overall workflow. Before introducing our method, we begin by re-examining traditional sample selection approaches from two perspectives.

\subsection{Per-Instance Selection Compared to One-Time Selection}
In studies on ICL, particularly those in the fields of NLP and CV \cite{liu-etal-2022-makes, zhang2023makes}, most existing works perform example selection separately for each test instance, often using methods such as $k$NN or clustering to identify similar and representative examples. We refer to this approach as per-instance selection.

However, in numerical data classification tasks, using a $k$NN-based per-instance selection strategy can easily bias the LLM toward predicting the majority label among the selected examples. This often causes the model to behave similarly to a standard $k$NN classifier, thereby undermining the unique advantages of LLMs.

In fact, in order to demonstrate that the ability of LLMs is not solely driven by $k$NN, \cite{liu-etal-2022-makes} introduces a baseline where $k$NN alone is used for prediction. The results show that $k$NN performs significantly worse than $k$NN+LLM. However, many of the tasks considered involve open-ended output spaces—for example, text generation tasks. As described in \cite{liu-etal-2022-makes}, “for text generation tasks, the target $y_1$ associated with the first retrieved example is directly used as the predicted output. ” Therefore, the mismatch between the retrieved target and the true output is almost inevitable, even when the examples are close in the embedding space.

Thus, the relatively poor performance of $k$NN in such tasks is expected and does not invalidate the potential overlap between $k$NN and LLM. If this bias is relatively subtle in non-classification tasks, it becomes especially evident in classification tasks.

Subsequent experiments further confirm this observation. Although $k$NN-based per-instance selection can achieve reasonably good prediction accuracy, its performance is often similar to that of a standard $k$NN classifier. In most cases, unless a very large model is used, it usually performs worse than $k$NN. Moreover, the cost of per-instance selection is substantial. It requires actively selecting examples for each test sample individually, often involving multiple iterations per selection. This results in high computational and time costs.

To address these issues, we propose a one-time selection approach. Instead of selecting examples repeatedly for each test instance, we select a fixed set of examples once from the training set at the beginning and use this same set for all subsequent predictions. This method offers significant advantages over per-instance selection in terms of efficiency and scalability, particularly in the following two aspects:
\begin{enumerate}
\item \emph{Reduced computational overhead}. It eliminates the need for repeated per-instance selection, avoiding the iterative process for each test sample.
\item \emph{Improved batch efficiency}. Since all test samples share the same in-context examples, we can batch multiple test inputs into a single prompt and obtain multiple predictions with one API call. In contrast, per-instance selection requires constructing one prompt per test instance, yielding only a single prediction at a time.
\end{enumerate}
Furthermore, in terms of prediction accuracy, our experiments show that performance improves as the size and capability of the LLM increase. On some datasets, the one-time selection strategy even outperforms state-of-the-art methods.

\subsection{Gold Criteria for Demonstrations}
Once the one-time selection strategy is adopted, the notion of similarity—which has served as a primary criterion in most prior few-shot demonstration selection methods—no longer applies, as there is no specific test instance to serve as a reference for measuring similarity. This calls for a major shift: we must focus on samples that best represent the entire input space rather than resemble an individual instance.

In conventional classification frameworks, constructing a robust decision boundary is critical for achieving strong generalization performance. Accordingly, three core criteria are widely adopted in active learning:
\begin{enumerate}
\item \emph{Informativeness}. Informativeness quantifies how challenging a sample is for the model to classify, typically indicating that it carries substantial information. Informative samples are expected to exert a notable influence on the refinement of the decision boundary. This criterion can be measured using various approaches, such as model uncertainty (e.g., predictive entropy, distance to the decision boundary, or confidence scores), expected model change, or expected error reduction.
\item \emph{Representativeness}. Representativeness measures how well a sample reflects the overall distribution of the input space, often based on its similarity to other samples \cite{Settles2009}. Representative samples are typically not outliers. A common strategy is to perform $k$-means clustering over the unlabeled pool and select samples closest to cluster centroids as proxies for the underlying data structure. In regression tasks, representativeness aids in capturing input space structure; however, for classification tasks, it plays a secondary role to informativeness in defining the decision boundary.
\item \emph{Diversity}. Diversity ensures that selected samples span a wide range of the input space, rather than clustering in a narrow region. In classification, this generally involves selecting samples along the decision boundary to maximize coverage. Techniques such as greedy sampling and $k$-means clustering are frequently employed to enhance sample diversity.
\end{enumerate}

However, when applying LLMs to EEG-based classification tasks, it remains unclear whether these principles still apply. To address this, we conducted a series of experiments to examine how effectively various selection strategies can activate the few-shot learning capabilities of LLMs.

Concretely, we evaluate three selection methods: (1) random selection as a baseline, (2) entropy-based selection, which identifies the most informative examples based on prediction uncertainty, and (3) k-means clustering, which selects examples that are both representative and diverse. For all methods involving distance computations, the Euclidean distance is used. Experiments are conducted on the well-established BCI Competition IV 2a dataset, focusing on a binary-class motor imagery task. The training and test sets each contain 144 trials, drawn from two separate sessions, with balanced class distributions.

Additionally, since only a small number of examples are used in few-shot prompting, we adopt a class-balanced selection strategy in all experiments to prevent the selected examples from being dominated by a single class, which could bias the LLM’s predictions. All methods are repeated 25 times, and the results are reported in Table~ref{tab:pre-exp}.

As shown in Table~ref{tab:pre-exp}, using k-means-selected samples as in-context examples leads to overall better prediction performance than random selection. This indicates that strategies based on representativeness and diversity are also effective for in-context example selection in LLMs. However, contrary to our expectations, using the most informative samples—those with the highest entropy—as in-context examples yields surprisingly poor results, with an average accuracy of only XX\%, significantly lower than that of random selection. This suggests that information-based selection strategies, which are among the most effective in traditional classification models, may completely fail in the context of in-context learning with large language models.

To better understand which types of samples contribute most to model performance, an additional set of experiments was conducted. Each sample in the training set was individually used as the sole in-context example, and the corresponding prediction accuracy was recorded. Based on these results, all samples were ranked by performance, and the top 10 most effective ones were selected. Their distribution was then analyzed using t-SNE, as shown in Figure~ref{fig:tsne} (Subject 8). Interestingly, these high-performing samples are not located near the decision boundary; on the contrary, most lie far from it. This pattern was consistently observed across multiple subjects.

Motivated by this observation, we took the opposite approach by selecting the least informative samples—those predicted by the model with the highest confidence. Using the same evaluation procedure, the results are reported in Table~ref{tab:pre-exp}. Remarkably, these low-entropy samples not only outperform random selection but also achieve better performance than the k-means-based selection strategy. Furthermore, to mitigate the risk of selecting outlier samples, we leveraged the known label information and proposed a local same-label purity method. This strategy further enhances the performance of the LLM, as demonstrated in subsequent experiments.

We hypothesize that, for classification tasks involving numerical data, few-shot prompting in LLMs relies more on analyzing the intrinsic characteristics of the data itself, rather than constructing a deep neural network as in fine-tuning. Consequently, more prototypical and easily classifiable examples may better represent the underlying characteristics of each class, thereby enabling more accurate predictions. In contrast, highly informative examples—those near the decision boundary and more difficult to classify—may introduce ambiguity and offer less effective guidance during inference.

\subsection{Purity-based Unique-Round Example Selection (PURE)}
Based on the preceding observations, we propose PURE (Purity-based Unique-Round Example Selection), a cost-effective strategy for selecting in-context examples in EEG-based tasks. The overall procedure is illustrated in Figure~\ref{fig:flowchart}.

We begin by applying standard preprocessing to the raw EEG signals, followed by task-specific hand-crafted feature extraction informed by domain knowledge. Specifically, for MI tasks, the EEG signals are band-pass filtered into 4 sub-bands within the 8–24 Hz range, each with a 4 Hz bandwidth. The CSP algorithm is then applied to each sub-band to extract 2 features, resulting in an 8-dimensional feature vector for each trial.

Next, for each feature vector in the training set, we identify its $k$ nearest neighbors and compute the proportion of neighbors that share the same class label—this value is referred to as the local same-label purity. The pseudocode of PURE is given in Algorithm~\ref{alg:PURE}. All training samples are then ranked based on their purity scores, and the top-$n$ most “pure” samples are selected as in-context examples. This purity-based selection strategy not only identifies the most prototypical samples within each class but also helps to avoid outliers, as samples surrounded by neighbors from different classes tend to receive lower purity scores and are thus less likely to be selected.

Moreover, although the method does not explicitly enforce diversity, we empirically observe that augmenting it with greedy diversity sampling degrades performance, suggesting that purity alone is a more effective criterion in this context.

Finally, the selected examples, along with their corresponding labels, are combined with task descriptions, background context, and explicit output instructions to construct the full in-context prompt, which is then provided to the LLM alongside the test input.

\begin{algorithm}[ht]
  \caption{Purity-based Unique-Round Example Selection (PURE)}
  \label{alg:PURE}
  \KwIn{
      N labeled samples, $\{\mathbf{x}_n\}_{n=1}^N$, where $\mathbf{x}_n \in \mathbf{R}^d$;\\
      \hspace*{3.1em} $C$, number of classes; \\
      \hspace*{3.1em} $M$, number of samples to select; \\
      \hspace*{3.1em} $K$, neighborhood size
  }
  \KwOut{A list of selected sample indices with balanced class distribution $L$.}
  
  Ensure $M$ is divisible by $C$; \\

  \ForEach{sample $n = 1$ to $N$}{
      Compute distances between $\mathbf{x}_n$ and all other samples; \\
      Find $K$ nearest neighbors of $\mathbf{x}_n$ (excluding itself); \\
      Compute same-label purity score:
      \[
      \text{purity}(\mathbf{x}_n) = \frac{\text{Number of same-label neighbors}}{K}
      \]
  }
  Group all samples by class label; \\
  Sort each group in descending order of purity score; \\
  \ForEach{class $c = 1$ to $C$}{
      Select top $M / C$ samples with highest purity; \\
      Add their indices to output list $L$;
  }
  \Return{Selected sample indices list $L$.}
\end{algorithm}

\section{Datasets}
This section introduces five MI datasets, one sleep dataset, and one epilepsy dataset used in our experiments.
\subsection{MI Datasets}
All MI datasets used in our experiments are binary classification tasks and were obtained using the MOABB framework \cite{jayaram2018moabb}. Specifically, two datasets from BCI Competition IV (2a and 2b) \cite{tangermann2012review} contain left-vs-right hand imagery, while the other three—BNCI2014002, BNCI2015001, and Weibo2014—contain right-hand vs. feet imagery.

Their experimental paradigms were similar: In each session, a subject sat comfortably in an armchair positioned in front of a computer screen. At the beginning of each trial, a fixation cross appeared on a black background, accompanied by a short auditory warning tone. After a brief delay, a directional cue in the form of an arrow pointing left, right, down, or up appeared on the screen, corresponding to one of the four MI classes: left hand, right hand, foot, or tongue. This cue remained visible throughout the task period and served as a prompt for the subject to begin the corresponding MI task. Subject performed the imagery task until the fixation cross disappeared. Each trial ended with a brief black screen before the next trial began \cite{tangermann2012review}.

\begin{enumerate}
  \item \emph{Left Hand vs. Right Hand Datasets}. 
  Dataset 2a comprises recordings from 9 subjects, with EEG signals collected from 22 channels at a sampling rate of 250 Hz. Although the original paradigm involves four MI tasks (left hand, right hand, feet, and tongue), only the left- and right-hand trials are used in our experiments. Each subject completed two sessions on different days, with 72 trials per class per session, totaling 144 trials per session.

  Dataset 2b also includes 9 subjects but uses only 3 bipolar EEG channels (C3, Cz, and C4), sampled at 250 Hz. Each subject participated in 5 sessions: the first 2 (screening) without feedback, and the last 3 with real-time feedback. During the feedback sessions, a smiley face was displayed and changed color based on the accuracy of the subject’s imagined movement.

  \item \emph{Right Hand vs. Feet Datasets}.
  BNCI2014002 includes 14 participants and follows a similar paradigm to 2a. Each subject completed 1 session with 8 runs (5 for training and 3 for evaluation), totaling 160 trials.

  BNCI2015001 adopts the Graz two-class synchronous MI paradigm, using EEG recorded from 3 Laplacian derivations. Data were sampled at 512 Hz and filtered using a 0.5–100 Hz bandpass filter with a 50 Hz notch filter. The last 3 subjects were excluded due to poor performance.

  Weibo2014 contains data from 10 right-handed participants who underwent a one week training phase prior to EEG recording. EEG was collected from 64 channels placed according to the international 10–20 system, bandpass filtered between 0.5–50 Hz, and downsampled to 200 Hz. Each participant completed 9 blocks of trials involving 6 MI tasks. Only right-hand and feet trials were used for binary classification in this study. From the original 60 usable channels, we selected 21 MI-related channels: FC3, FC1, FCz, FC2, FC4, C5, C3, C1, Cz, C2, C4, C6, CP3, CP1, CPz, CP2, CP4, P3, P1, P2, and P4.

\end{enumerate}

\subsection{Sleep Datasets}
The Sleep-EDF Expanded (Sleep-EDFx) dataset is intended for sleep research, particularly for sleep stage classification. It contains 197 full-night polysomnographic (PSG) recordings, including EEG (Fpz–Cz and Pz–Oz), EOG, EMG, and event markers. Corresponding hypnograms (sleep stage annotations) were manually scored by trained technicians following the Rechtschaffen and Kales manual and are provided alongside the recordings.

The data originate from two studies: the Sleep Cassette Study and the Sleep Telemetry Study. The main difference is that the Sleep Cassette Study investigates the effect of age on sleep in a home environment over 2 nights (approximately 20 hours each), while the Sleep Telemetry Study examines the effect of temazepam (a sleep medication) in a hospital setting over 2 nights (approximately 9 hours each), using a high-quality telemetry system.

In our experiments, we focused on data from the Sleep Cassette Study and used only EEG channels for a five-stage sleep classification task. Due to the large volume of data, we selected recordings from 9 subjects, using 1 night of data per subject.

During the signal processing and feature extraction stages, EEG data from the Sleep-EDFx dataset were first bandpass filtered between 0.5 Hz and 35 Hz. Since the recordings span an entire night and include prolonged wake periods at the beginning and end, only the first and last 30 minutes of wakefulness were retained to reduce redundancy. Sleep stages were labeled according to the AASM standard and grouped into five classes: Wake (W), N1, N2, N3, and REM. Each trial was segmented into non-overlapping 30-second epochs.

To extract frequency-domain features, four bandpass filters were applied to isolate the following frequency bands: 0.5–4 Hz, 4–8 Hz, 8–12 Hz, and 12–16 Hz. For each band, the root mean square (RMS) power was computed on a per-channel basis, defined as the mean of the squared signal amplitude across all samples within the trial. This process yielded a feature representation with shape (N,C×B), where N is the number of trials, C is the number of EEG channels, and B=4 is the number of frequency bands.

Subjects were monitored over multiple days following the withdrawal of anti-seizure medication to capture seizure activity and evaluate their suitability for surgical intervention. In total, 182 seizures were annotated with precise onset and offset timings.

  All signals were sampled at 256 Hz with 16-bit resolution. Most recordings contain 23 EEG channels, though a few have 24 or 26. Electrode placement follows the International 10–20 system for EEG acquisition.

  \item \emph{TUH EEG Epilepsy Corpus}.

\section{PL: The General Idea} \label{sect:PL}

This section introduces the general idea of PL, and illustrates it by a simple example.

Formally, we define a \emph{patch} as a connected polyhedron in the input domain. For example, a patch in a 1D input domain is an interval, as shown in Fig.~\ref{fig:1Dpatch}, and a patch in a 2D input domain can be a rectangle, an ellipse, etc., as shown in Fig.~\ref{fig:2Dpatch}. For ease of implementation, in this paper we only consider polyhedra whose number of surfaces (sides) equals the dimensionality of the input domain, and each surface (side) is perpendicular to an axis of the input domain, e.g., an interval in the 1D input domain [Patches~1-3 in Fig.~\ref{fig:1Dpatch}], and a rectangle in the 2D input domain [each side is perpendicular to an axis, such as Patch~1 in Fig.~\ref{fig:2Dpatch}].

\begin{figure}[htbp]\centering
\subfigure[]{\label{fig:1Dpatch}   \includegraphics[width=.47\linewidth,clip]{Fig2a}}
\subfigure[]{\label{fig:2Dpatch}    \includegraphics[width=.47\linewidth,clip]{Fig2b}}
\caption{Patches in 1D and 2D input domains.} \label{fig:patchs}
\end{figure}


\subsection{Steps of PL}

Given $L$, the number of patch models to be trained, PL consists of the following three steps:
\begin{enumerate}
\item Train an initial global model using all training data.
\item Identify $L$ patches from the initial global model, which contribute the most to the learning error, and train a (local) patch model for each such patch.
\item Update the global model using training data that do not fall into any patch.
\end{enumerate}
The rationale for the last step is that, when the default global model is first trained, it is forced to fit all training examples, some of which, e.g., those within the $L$ patches identified in Step (2), may be really difficult to fit. Since these difficult training examples have been handled by the patch models in Step (2), we can update the default global model to fit only the examples outside of the $L$ patches. This should be much easier than fitting all examples together, and hence the root mean squared error (RMSE) of the default global model may be reduced. Since in Step (3) the training examples for the updated global model are all outside of the patches, the updated global model is not suitable for inputs within any of the $L$ patches: although it can output an arbitrary value for such an input, this does not matter, since the patch models are used to handle such cases.

The idea of PL may be intuitively understood by making the following analogy. Consider a sculptor who is sculpting a human figure. After his first pass at this, the sculptor examines the entire figure and notices that improvements need to be made to certain parts of the figure. The sculptor does not throw out the entire figure and begin a new. Instead, he zooms into those parts that need more work, after which he blends in the refined portions of the figure with the rest of the figure. He continues such iterative refinements until he is satisfied with the entire figure. Each patch in PL is analogous to a part in the figure that needs more work. In traditional ensemble learning approaches, usually each base/weak learner also focuses on the entire figure, instead of a part of it.

\subsection{Determine the Optimal Number of Patch Models}

An important question in PL is how to determine $L$, the optimal number of patch models. Increasing $L$ is equivalent to increasing the model complexity in traditional machine learning. So, some analogy also applies here: generally, the training performance increases with $L$, but the test (generalization) performance may first increase and then decrease (indicating overfitting). Inspired from some common practices in traditional machine learning for reducing overfitting \cite{Duda2000,Hastie2009}, there are at least two approaches to determine $L$ in PL:
\begin{enumerate}
\item \emph{Early stopping}. We first partition all available labeled data into a training set and a validation set (these two sets should not overlap). Then, we train different PL models with different $L$ on the training set, and monitor their performances on the validation set. The one with the best validation performance is chosen as the final PL model.
\item \emph{Regularization}. We view $L$ as an indicator of model complexity, and regularize it in the loss function so that $L$ cannot be too large. We then pick the PL model that results in the smallest loss. There could be different choices and implementations of the regularization, similar to the case in traditional machine learning.
\end{enumerate}

The second idea is used in this paper. We mainly consider regression problems, and use the following loss function, which showed satisfactory performance in our experiments:
\begin{align}
\ell= rmse(\mathbb{D})\times (L+1)^\alpha, \label{eq:loss}
\end{align}
where $rmse(\mathbb{D})$ is the training RMSE on the training set $\mathbb{D}$, and $\alpha>0$ is a trade-off parameter between the RMSE and the model complexity. A smaller $\alpha$ prefers a more accurate but maybe more complex model, and a larger $\alpha$ prefers a simpler model with a smaller number of patches, but the RMSE maybe large. Our experiments showed that $\alpha=1/4$ gave satisfactory performance, so $\alpha=1/4$ was used in this paper.

\subsection{PL Illustrated by a Simple Example}

Next, we use a simple regression problem with only one input to illustrate the above procedure.

\begin{align}
\theta_s=\arg\min_{\theta_s}\left[\sum_{i=1}^{n_s}(y_{s,i}-x_{s,i})^2+\lambda_1\|\theta_s\|^2\right]
\end{align}

Assume we have $N=601$ training examples $(x_n,y_n)$, $n=1,...,N$, generated from the unknown function
\begin{align}
y=\left\{\begin{array}{ll}
           x+x^2+8\sin(x), & x\in[1.5,3] \\
           x+x^2+2\sin(x), & x\in[4,5] \\
           x+x^2, & \mbox{otherwise}
         \end{array}\right. \label{eq:g}
\end{align}
where $x\in[0,6]$ and 601 uniform samples are used. The true relationship between $y$ and $x$ is plotted as the dotted black curve in Fig.~\ref{fig:gPL0}. We would like to build a PL model to fit it. The basic nonlinear regression model used is $y=f(x)=\beta_0+\beta_1x+\beta_2x^2$.

\begin{figure}[htbp]\centering
\subfigure[]{\label{fig:gPL0}   \includegraphics[width=.47\linewidth,clip]{Fig3a}}
\subfigure[]{\label{fig:gRMSE0}    \includegraphics[width=.47\linewidth,clip]{Fig3b}}
\caption{The general idea of PL, illustrated by a simple 1D curve fitting problem. (a) fitting by one global model $f_g(x)$; (b) the fitting error of $f_g(x)$.} \label{fig:gPL}
\end{figure}

The first step is to build a global model $f_g(x)$ using all $N$ training examples. The fitted model is $f_g(x)=0.68+2.63x+0.63x^2$, plotted as the solid blue curve in Fig.~\ref{fig:gPL0}. The fitting errors are shown in Fig.~\ref{fig:gRMSE0}. Clearly, the RMSE is large, i.e., a single global model cannot fit the data well.

By visual examination of Fig.~\ref{fig:gRMSE0}, we can see that the fitting errors are large when $x\in[1.5,3]$. So, the next step is to build a patch model for $x\in[1.5,3]$. Using only the training examples within this patch, we obtain the first patch model $f_1(x)=1.65+9.81x-2.01x^2$. $f_g(x)$ and $f_1(x)$ together reduce the training RMSE from $2.560$ to $1.654$, and the loss $\ell$ from $2.560$ to $1.967$, as shown in Fig.~\ref{fig:gRMSE1}. The fitting accuracy is improved, but the RMSE may still be too large. So, a second patch model may be needed.

By visual examination of Fig.~\ref{fig:gRMSE1}, we can see that the fitting errors are large when $x\in[4,5]$. So, the next step is to build a patch model for $x\in[4,5]$. Using only the training examples within this patch, we obtain the second patch model $f_2(x)=19.29-8.03x+1.96x^2$. $f_g(x)$, $f_1(x)$ and $f_2(x)$ together further reduce the training RMSE to $1.332$, and the loss to $1.753$, as shown in Fig.~\ref{fig:gRMSE2}.

Assume at this point we do not want to add more patches. The final step is then to update the default global model, using all training examples outside of the two patches.  The updated global model is $f'_g(x)=x+x^2$, identical to the last case in (\ref{eq:g}). This step reduces the RMSE to $0.026$, and the loss to $0.035$, as shown in Fig.~\ref{fig:gRMSE3}.

For the above simple 1D curve fitting example, the final PL model can be easily represented as:
\begin{align}
y=\left\{\begin{array}{ll}
           f_1(x)=1.65+9.81x-2.01x^2, & x\in[1.5,3] \\
           f_2(x)=19.29-8.03x+1.96x^2, & x\in[4,5] \\
           f'_g(x)=x+x^2, & \mbox{otherwise}
         \end{array}\right. \label{eq:g2}
\end{align}

Generally, once the PL models are trained, the logic for determining which model to use for a new input is shown in Fig.~\ref{fig:PLmodel}. We first determine if the input falls into any patch. If yes, then the corresponding patch model is used to compute the output. Otherwise, the global model is used.

\begin{figure}[htbp]         \centering
\includegraphics[width=.6\linewidth,clip]{Fig4}
\caption{The logic for determining which model to use in PL.} \label{fig:PLmodel}
\end{figure}


For a well-optimized fuzzy system, transition from one rule partition to another changes the functional form of the input-output mapping. For example,  assume $x_m$ is the only input of the TSK fuzzy system, which has the following three rules:
\begin{align*}
R_1: &\mbox{ IF } x_m \mbox{ is } A_1, \mbox{ THEN } y=y_1(x_m)\\
R_2: &\mbox{ IF } x_m \mbox{ is } A_2, \mbox{ THEN } y=y_2(x_m)\\
R_3: &\mbox{ IF } x_m \mbox{ is } A_3, \mbox{ THEN } y=y_3(x_m)
\end{align*}
where $y_1(x_m)$, $y_2(x_m)$ and $y_3(x_m)$ are different functions of $x_m$. In Partition $P(1|x_m)$, only Rule $R_1$ is fired, and hence the fuzzy system output is $y=f_1(x_m)$; in Partition $P(2|x_m)$, both Rules $R_1$ and $R_2$ are fired, and hence the fuzzy system output is:
\begin{align}
y=\frac{\mu_{A_1}(x_m)y_1(x_m)+\mu_{A_2}(x_m)y_2(x_m)}{\mu_{A_1}(x_m)+\mu_{A_2}(x_m)};
\end{align}
in Partition $P(3|x_m)$, only Rule $R_2$ is fired, and hence the fuzzy system output is $y=f_2(x_m)$. Clearly, the functional forms of $y$ in the different rule partitions are different. It is reasonable to believe this is because the (unknown) groundtruth functional form changes significantly from one rule partition to another, and hence the fuzzy system uses different functional forms in different rule partitions to accommodate it. Thus, we can consider each such partition as a patch candidate\footnote{This is just one simple way to initialize the patch candidates. There may be better ways to do this.}.

According to Pedrycz \cite{Pedrycz2018}, \emph{``by information granules one regards a collection of elements drawn together by their closeness (resemblance, proximity, functionality, etc.) articulated in terms of some useful spatial, temporal, or functional relationships. Subsequently, Granular Computing is about representing, constructing, processing, and communicating information granules."} All points within a first-order rule partition fire the same number of same rules, and hence they resemble each other. So, each first-order rule partition can be viewed as an information granule, and PL can be viewed as a form of granular computing.

\subsection{Implementation Details}

For the ease of programming implementation, we can use a single index $k\in[1,K]$ to denote a patch candidate (first-order rule partition) $(P(k_1|x_1),P(k_2|x_2),...,P(k_M|x_M))$, where
\begin{align}
k&=(k_1-1)\cdot \prod_{m=2}^M K_m+(k_2-1)\cdot \prod_{m=3}^M K_m \nonumber \\
 &\quad +\cdots+(k_{M-1}-1)\cdot K_M+k_M\nonumber \\
&=k_M+\sum_{m=1}^{M-1}\left[ (k_m-1)\cdot \prod_{p=m+1}^M K_p\right] \label{eq:k}
\end{align}
For example, assume the fuzzy system has two inputs ($M=2$), $x_1$ and $x_2$, each with five first-order rule partitions ($K_1=K_2=5$) shown in Fig.~\ref{fig:Partition}. Then, (\ref{eq:k}) becomes $k=(k_1-1)\times K_2+k_2$. The partition $(P(1|x_1),P(1|x_2))$ is mapped to $k=(1-1)\times 5+1=1$, $(P(1|x_1),P(2|x_2))$ to $k=(1-1)\times 5+2=2$, $\cdots$, $(P(2|x_1),P(1|x_2))$ to $k=(2-1)\times5+1=6$, $\cdots$, and $(P(5|x_1),P(5|x_2))$ to $k=(5-1)\times 5+5=25$.


For a given $k\in[1,K]$, we can also map it back to a first-order rule partition $(P(k_1|x_1),P(k_2|x_2),...,P(k_M|x_M))$:
\begin{align}
k_1&=int\left(\frac{k-1}{\prod_{m=2}^M K_m}\right)+1 \label{eq:k1}\\
k_2&=int\left(\frac{k-1-(k_1-1)\cdot \prod_{m=2}^M K_m}{\prod_{m=3}^M K_m}\right)+1\\
k_m&=int\left(\frac{k-1-\sum_{i=1}^{m-1}\left[(k_i-1)\cdot \prod_{p=i+1}^M K_p\right]}{\prod_{p=m+1}^M K_p}\right)+1\\
k_M&=k-\sum_{m=1}^{M-1}\left[ (k_m-1)\cdot \prod_{p=m+1}^M K_p\right] \label{eq:kM}
\end{align}
where $int(x)$ means the integer part of $x$, e.g., $int(2.0)=2$ and $int(2.9)=2$. Using again the above example, when $k=6$, we have $k_1=int(\frac{k-1}{K_2})+1=int(\frac{6-1}{5})+1=2$ and $k_2=k-(k_1-1)\times K_2=6-(2-1)\times 5=1$, and hence the mapped first-order rule partition for $k=6$ is $(P(2|x_1),P(1|x_2))$.

In summary, the pseudo-code\footnote{A sample Matlab implementation is available at https://github.com/drwuHUST/Patch-Learning.} in Algorithm~\ref{alg:PLFS} implements the three generic PL steps described at the beginning of Section~\ref{sect:PL} using fuzzy systems. Its limitations and potential improvements are discussed in Section~\ref{sect:limitations}, after some experiments to demonstrate its capability are described in the next section.

\begin{algorithm}[htbp]
\KwIn{$N$ labeled training examples, $\{(\mathbf{x}_n,y_n)\}^N_{n=1}$, where $\mathbf{x}_n\in\mathbb{R}^{M\times 1}$\;
\hspace*{9mm} $T$ unlabeled examples, $\{\mathbf{x}_t\}_{t=1}^T$\;}
\KwOut{The PL model predictions for $\{\mathbf{x}_t\}_{t=1}^T$.}
\tcp{Train the PL model}
Train a global fuzzy model using all $N$ training examples\;
\For{$m=1,...,M$}
{Identify the first-order rule partitions for the $m$th input domain of the global fuzzy model\;}
Index the partitions using $k$ in (\ref{eq:k})\;
Include all partitions in the candidate pool\;
$l=1$\;
    \While{$l\le L$}{
    Identify from the candidate pool the partition giving the maximum SSE\;
    Record the location of the partition as the $l$th patch\;
    Train a patch fuzzy model using only the training examples within the $l$th patch\;
    \If{the $l$th model is successfully trained\footnotemark{}}
    {$l=l+1$\;}
    Remove the above patch from the candidate pool\;}
\caption{PL using fuzzy systems.} \label{alg:PLFS}
\end{algorithm}

\section{Conclusions} \label{sect:conclusion}

When the performance of a machine learning model is not satisfactory, there are different strategies to improve it, including designing a deeper, wider, and/or more nonlinear model, and ensemble learning (aggregate multiple base/weak learners in parallel or in series). This paper has proposed a novel strategy, \emph{patch learning}, to improve the performance of a machine learning model. It first identifies a few patches from the initial model, which contribute the most to the learning error. Then, a (local) patch model is trained for each such patch, using only training examples falling into the patch. Finally, a global model is trained using training data that do not fall into any patch. To use the PL model, we first determine if the input falls into any patch. If yes, then the corresponding patch model is used to compute its output. Otherwise, the global model is used. Five experiments on different regression problems verified the effectiveness of the proposed PL approach: as more patch models are added, the overall RMSE decreases. We also defined a loss function for determining the optimal number of patches, considering the trade-off between RMSE and model complexity.

It should be emphasized that although this paper focuses on PL using fuzzy systems, the idea is generic: any machine learning algorithm can be used as the patch model, and the patch models can also be trained using different machine learning algorithms.
